# 架构说明

## 分层

1. Skill 层：50 个独立育儿 Agent Skill，每个 Skill 有自己的 `SKILL.md` 和执行代码。
2. Schema 层：统一输入输出，便于平台做校验、日志和回放。
3. Runtime 层：`src/runner.py` 是可替换执行入口。
4. Adapter 层：OpenClaw / Hermes 的注册清单。
5. Governance 层：风险边界、隐私保护、人工核验和复盘机制。

## 路由建议

- 健康记录类：优先提醒边界，不做诊断。
- 教育陪练类：优先启发，不直接替孩子完成。
- 消费决策类：优先对比和核验，不替家长付款/承诺。
- 情绪沟通类：优先共情和安全，不做心理治疗。

## 数据闭环

每个 Skill 的长期价值来自记录沉淀：

`事件日志 → 结构化档案 → 周期趋势 → 个性化建议 → 复盘反馈 → 下一轮计划`
